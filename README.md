# 내 마당에 운석이 떨어졌다!

주어진 오브젝트인 운석을 직접 타격하고, 파편 재화를 모아 업그레이드와 자동화 요소를 확장하는 클리커 기반 방치형 게임입니다.

## 프로젝트 정보

- 기간: 2026.05.11 - 2026.05.22 (약 2주)
- 인원: 1인 개발
- 기술: C++20, Unreal Engine 5, Blueprint, Rider, Git/GitHub
- 역할: 게임 기획, 클라이언트 프로그래밍, UI 제작, 레벨 구성
- 링크: https://github.com/J0Min/Clicker

## 핵심 기능

- 운석 타격 시 타격 위치에 파편과 이펙트 생성
- 파편 재화를 활용한 업그레이드 상점
- 레이저를 통한 자동화 공격
- 드론을 통한 파편 자동 수집
- 재화와 업그레이드 상태를 보여주는 UI
- 운석 파괴 후 엔딩 및 시작 화면

## 실행 방법

1. 저장소를 클론합니다.
2. Unreal Engine 5로 `.uproject` 파일을 엽니다.
3. 프로젝트를 빌드한 뒤 에디터에서 실행합니다.
4. 운석을 타격해 파편을 생성하고, 파편 재화로 업그레이드를 구매합니다.
