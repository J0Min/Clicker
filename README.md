# 내 마당에 운석이 떨어졌다! — 운석을 파괴하고 평온한 마당을 되찾는 방치형 클리커 게임

## 🚀 핵심 기능
1. **정밀한 파편 생성 시스템**
   * `Sphere Trace By Channel`을 활용해 타격 위치를 정확히 계산하여 즉각적인 파편 액터와 나이아가라 이펙트를 스폰합니다. 어느 지점을 쳐도 느껴지는 생생한 타격감을 구현했습니다.
2. **효율적인 자동화 및 업그레이드 루프**
   * 별 파편을 소비해 클릭 효율을 높이거나 드론/레이저 장비를 배치하는 시스템입니다. `ListView`와 인터페이스 기반의 상점 UI를 통해 기하급수적인 성장의 재미를 제공합니다.
3. **스마트 드론 수집 시스템**
   * 매니저 액터가 레벨 내 파편을 주기적으로 탐색하여 드론 배열에 매칭합니다. 플레이어 대신 재화를 자동으로 수집하여 완전한 방치형 플레이로의 전환을 지원합니다.

## 💡 기술적 도전 및 해결
**문제: 드론이 타겟 파편을 찾지 못하고 엉뚱한 곳으로 날아가는 현상**
* **원인**: 드론이 이동하는 사이 다른 드론이나 플레이어가 파편을 먼저 수집하여 참조 대상이 소멸(Null)되었기 때문입니다.
* **해결**: 대상이 Null일 경우 즉시 스포너 위치로 복귀하도록 로직을 보완하고, `Set World Location` 이동 시 루트와 메쉬가 엇나가지 않도록 Teleport 항목을 조정하여 의도된 방향으로 이동하게 개선했습니다.
* **배움**: 액터 간 상호작용 시 객체의 생명 주기를 고려한 예외 처리가 얼마나 중요한지 깨달았습니다.

## 📦 빌드 및 실행 방법
1. **GitHub 저장소**를 클론합니다.
2. `.uproject` 파일을 우클릭하여 **Generate Visual Studio project files**를 선택합니다.
3. 생성된 `.sln` 파일을 Visual Studio 2026에서 열고 **Build**를 수행합니다.
4. 언리얼 에디터에서 프로젝트를 열고 **Play** 버튼을 누릅니다.
   * **좌클릭**: 운석 타격 및 파편 생산
   * **Tab**: 상점 UI 열기/닫기
